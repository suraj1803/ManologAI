Background & Motivation

The Problem: The Fragmented Quantified-Self

B.Tech IT (Sem VII)
⚠️ Current Industry Challenges
  • Siloed Life Data: Users record habits in one app, journals in Notion, mood in Daylio, and sleep in health trackers without interoperability.
  • Zero Cross-Domain Correlation: Isolated apps cannot answer critical lifestyle questions: "How does sleeping under 6.5 hours impact my daytime stress and work output?"
  • Absence of Data Integrity: Most self-tracking apps permit retroactive editing, leading to cognitive bias and inflated streaks.
  • High Logging Friction: Dispersed workflows cause user burnout within 2–3 weeks.
🎯 Project Objectives
  • Unified Behavioral Intelligence: Merge qualitative journaling with quantitative time, expense, and habit tracking in a single ecosystem.
  • Personal Data Scientist: Implement statistical algorithms to expose hidden correlations between sleep, screen time, habits, and emotional state.
  • Integrity Enforcement: Implement an immutable 24-hour write lock to prevent retroactive revisionism.
  • Frictionless UX: Native Progressive Web App (PWA) with VAPID web push reminders under a sub-2-minute daily routine.

Architectural Principles & Pipeline
  • Decoupled Micro-layering: Client-side rendering backed by stateless REST endpoints ensuring fast Time-To-Interactive (TTI).
  • Compound Constraints: Database models enforce { user: 1, date: 1 } unique compound indices to eliminate race conditions and duplicates.
  • Proactive Push Scheduler: Node.js background worker executes 60s cron evaluation with automatic dead-subscription purging (HTTP 410).
  • Dual-Layer Fallback: Seamless handoff between OS Web Push and in-browser Notification API.

Technical Innovations

Key Technical Innovations & Engineering Highlights

Core Innovations
🔒 24-Hour Integrity Lock Engine

Behavioral self-reports suffer when users falsify history retroactively.

  • All diary, emotion, and time tracking entries enforce a strict temporal lock threshold (24 hours).
  • Future date submissions are strictly rejected at the API middleware level.
  • Guarantees pristine, unpolluted datasets for meaningful statistical analytics.
🧠 Cross-Domain Correlation Engine

Transforms raw, disparate inputs into actionable personal intelligence.

  • Computes multi-dimensional Pearson correlation matrices (e.g., Sleep Duration vs. Emotional Well-being).
  • Identifies day-of-week drop-off anomalies (e.g., weekend habit completion drop rates).
  • Renders multidimensional radar charts visualizing life balance symmetries.
🛡️ Robust Session & Token Rotation
  • Dual-token architecture: Short-lived access token (15 min) + Refresh token (7 days).
  • Stored in httpOnly, SameSite: Lax cookies preventing XSS-based token theft.
  • Automatic token rotation with token reuse detection and multi-device session pruning.
🔔 VAPID Web Push & Mobile PWA
  • Voluntary Application Server Identification (VAPID) push messaging without proprietary SDKs.
  • Progressive Web App (PWA) with installable standalone manifestation and custom splash screen.
  • Service Worker precaching of critical runtime chunks for offline continuity.
